# Pocketwise — Student Expense Tracker

A simple, responsive expense tracker designed around student life. Log day-to-day spending, set a monthly budget, and see where your money goes.

## Run it

Open `index.html` in a modern browser. No build step or package installation is required.

## What it does

- Add and delete expenses with a description, amount, category, and date.
- Review spending totals and budget progress for the selected month.
- Visualize daily spending and category totals.
- Search transactions and filter by category.
- Save expenses and your monthly budget in this browser on this device.

## Privacy

The app uses browser `localStorage`; it does not send expense information to a server. Clearing this browser's site data removes the locally saved information. The app currently formats amounts in Indian rupees.
